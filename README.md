# Flow Studio

محرر فلو للطاقة يعمل مباشرة من ملفات HTML، باستخدام مجسمات Solar / Battery / Inverter / Grid / Home الموجودة في ملفاتك السابقة، ونفس أسلوب الخطوط الفاتحة ذات الزوايا الدائرية والحركة الزرقاء.

## الشاشات الجديدة

- **Loading**: تظهر أثناء فك صور المجسمات المضمّنة، وتعرض تقدمًا فعليًا وحالة نجاح أو خطأ مع إعادة المحاولة.
- **Landing**: صفحة تعريف عربية مع معاينة متحركة، شرح قدرات الرسم والبيانات والتصدير، وروابط المحرر والتوثيق.
- **Docs**: خطوات الاستخدام وأمثلة قابلة للنسخ للويب وNext.js وVue وFlutter Android/iOS، وشرح البيانات والحالات وصيغ التصدير.

يفتح المشروع على صفحة التعريف بعد اكتمال التحميل. انتقل من الأزرار العلوية، أو افتح أحد الروابط داخل نفس الملف:

| الرابط | الشاشة |
| --- | --- |
| `#home` | صفحة التعريف |
| `#editor` | المحرر |
| `#docs` | دليل الاستخدام |
| `#docs/web` | التضمين على الويب |
| `#docs/flutter` | Flutter |
| `#docs/api` | القيم والأسماء والحالات |
| `#docs/exports` | صيغ التصدير |
| `#loading` | شاشة التحميل بعد اكتمال التجهيز |

التنقّل لا يعيد تحميل المشروع ولا يغيّر بياناته. جدول المعرّفات داخل التوثيق يعرض عناصر وخطوط المخطط الحالي. أمثلة `energyFlow` تخص HTML الناتج من **Export → HTML**؛ أما واجهة المحرر فهي `flowStudio`. ملف الرسم المصدَّر يحتوي على الفلو وواجهة التحكم فقط.

## تشغيل سريع

1. افتح `Flow-Studio.html` الموجود في جذر المشروع في Chrome أو Edge أو Safari أو Firefox حديث.
2. اختر مخطط Hybrid أو Generator backup أو Solar pump أو Blank canvas.
3. أضف العناصر من القائمة، واسحبها على مساحة الرسم.
4. اضغط **Connect** ثم العنصر المصدر والعنصر الهدف.
5. اضغط على عنصر أو خط لتعديل الخصائص.
6. اضغط **Save project** للاحتفاظ بنسخة قابلة للتحرير، أو **Export** لاستخراج النتيجة.

لا يحتاج المحرر إلى إنترنت أو npm أو سيرفر. النسخة المقسّمة في `src/index.html` تعمل أيضًا مباشرة. لحفظ الملفات من هاتف أو تابلت قد تحتاج إلى فتح الملف في متصفح كامل بدلًا من معاينة تطبيق الملفات.

## ماذا تستطيع التحكم فيه؟

- اسم كل عنصر، القيمة، الوحدة، التيار ووحدته، الكفاءة، ونص الحالة.
- `active`: العنصر واضح، والخط يتحرك.
- `inactive`: العنصر باهت، والخط الأساسي ظاهر بدون حركة.
- `hidden`: العنصر أو الخط مخفي بالكامل.
- حالات العناصر والخطوط مستقلة؛ إخفاء عنصر لا يغير حالة الخطوط المتصلة به.
- موقع العنصر وأبعاده، موقع التسميات، حجم النص ولونه.
- لون الخط الأساسي ولون الحركة، العرض، اتجاه الحركة، مدة الدورة، واستدارة الزوايا.
- مسارات تلقائية أو نقاط تحكم يدوية يمكن سحبها أو كتابة إحداثياتها.
- إضافة صور PNG/JPEG/WebP أو SVG يتضمن أصوله داخله. يحتفظ الاستيراد بالـ CSS الآمن الداخلي؛ الموارد الخارجية يجب تضمينها أولًا.
- التراجع والإعادة، تكبير مساحة الرسم، شبكية المحاذاة، وحفظ مسودة محلية.

الحقول تعرض البيانات فقط. لا توجد محاكاة للطاقة ولا تعديل لمحاكاة ملفاتك السابقة.

## صيغ التصدير

| الصيغة | المحتوى |
| --- | --- |
| `.html` | مخطط متحرك مستقل، الأصول مضمّنة، وواجهة JavaScript لتحديث البيانات والحالات |
| `.svg` | مسارات متجهية متحركة، صور مضمّنة، وتسميات نصية قابلة للتحرير |
| `.png` | لقطة ثابتة عند الوقت المحدد، بدقة 1× أو 2× أو 3×، مع خيار خلفية شفافة |
| `.lottie.json` | حركة Lottie فعلية: مسارات متجهية، صور مضمّنة، وصور للتسميات الحالية |
| `.flow.json` | ملف المشروع القابل لإعادة الفتح والتحرير، بما فيه الأصول المستخدمة |

تستخدم الشاشة وSVG وPNG وLottie إحداثيات Bézier نفسها. يمنع التصدير إذا خرج المحتوى خارج مساحة الرسم؛ استخدم **Canvas settings → Fit canvas to content** لضبطها.

Lottie يحفظ البيانات والحالات الحالية عند التصدير، وتستمر حركة الخطوط. لا يحتوي على واجهة التحكم الخاصة بملف HTML. التسميات في Lottie صور بدقة 3× للحفاظ على شكل الخط والعربية دون الاعتماد على خطوط جهاز العرض. صور المجسمات الأصلية كانت صورًا مضمّنة داخل SVG؛ المسارات هي الجزء المتجهي. قُصت هوامش الصور الشفافة وحُفظت حتى 720 بكسل في أكبر بُعد لتناسب ملفات العرض. يمكن استيراد صورة أصلية أعلى دقة إذا احتجت إلى عرض المجسم بحجم أكبر.

مدة حركة Lottie المشتركة هي المضاعف المشترك لدورات الخطوط بعد تقريبها إلى إطار 1/30 ثانية. هذا يحافظ على سرعة كل خط وحلقة متصلة. إذا تجاوزت الحلقة المشتركة عشر دقائق، يطلب المحرر استخدام مدد دورات متوافقة؛ استعمال نفس مدة الدورة لكل الخطوط هو الأسهل.

SVG يستخدم Arial مع بديل sans-serif؛ قد تختلف قياسات الخط قليلًا بين أنظمة التشغيل. PNG وصور تسميات Lottie تُرسم على الجهاز الذي ينفذ التصدير. تم التحقق من JSON باستخدام محرك Airbnb `lottie-web` (SVG renderer). تختلف ميزات مشغلات Lottie الأخرى؛ اختبر ملفك على المشغل الذي تستخدمه.

## التحكم من JavaScript في HTML المُصدَّر

```js
// active | inactive | hidden
energyFlow.setNodeState('solar', 'active');
energyFlow.setFlowState('grid', 'hidden');

energyFlow.setNodeData('solar', {
  name: 'الطاقة الشمسية',
  value: 8.7,
  unit: 'kW',
  current: 12.4,
  currentUnit: 'A',
  efficiency: 96.8,
  status: 'يعمل',
  showDetails: true
});

// 1 = source → target; -1 = target → source
energyFlow.setFlowDirection('battery', -1);
energyFlow.pause();
energyFlow.play();

// Compatibility aliases from the previous discussion:
setNodeState('battery', 'inactive');
setFlowState('battery', 'active');
```

أو إرسال تحديث بيانات:

```js
window.dispatchEvent(new CustomEvent('energy-flow-data', {
  detail: {
    nodes: { solar: { value: 8.7, unit: 'kW' } },
    flows: { solar: 'active', grid: 'inactive' }
  }
}));
```

المعرّفات تظهر تحت عنوان الخصائص عند اختيار العنصر أو الخط. العناصر الافتراضية: `solar`, `battery`, `inverter`, `grid`, `home`, `junction`. في مخطط المولد، يبقى معرّف عنصر الاحتياط `grid` للتوافق بينما نوعه `generator`.

## دمجه داخل Next.js أو Vue

ضع ملف HTML المُصدَّر في مجلد الملفات الثابتة للمشروع واعرضه في iframe. لا يعتمد محرك الفلو على React أو Vue:

```html
<iframe
  src="/hybrid-energy-flow.html"
  title="Energy flow"
  style="width:100%;aspect-ratio:1000/650;border:0"
></iframe>
```

إذا كان الملف من نفس origin، يمكن استدعاء `iframe.contentWindow.energyFlow` بعد حدث `load`. للوصول المباشر من مكوناتك، يمكن تحميل `core.js` واستخدام `FlowCore.render(project)` بدلًا من iframe؛ استدعاء الدوال يكون في المتصفح.

## تقسيم المصدر

- `src/index.html`: واجهة المحرر.
- `src/styles.css`: تصميم المحرر والاستجابة للموبايل.
- `src/screens.css`: تصميم شاشات Loading وLanding وDocs.
- `src/screens.js`: التنقّل، تحميل الصور، معاينة الفلو، ونسخ أمثلة التوثيق.
- `src/core.js`: النموذج، مسارات Bézier، الرسم والتصدير.
- `src/app.js`: السحب، الخصائص، التراجع، الحفظ والاستيراد.
- `src/assets.json`: الأصول المستخدمة.
- `src/assets-data.js`: الأصول وكود المحرك المضمّن لتصدير HTML دون شبكة.
- `src/build.py`: تجميع النسخة المستقلة.
- `examples/`: ملفات مُصدَّرة جاهزة من المخطط الافتراضي.

بعد تعديل المصدر، شغّل:

```sh
python src/build.py
```

ينشئ `Flow-Studio.html` في جذر المشروع ويحدّث `assets-data.js`. لا توجد مكتبات JavaScript لازمة للتشغيل.

## ملاحظات الحفظ

الحفظ المحلي مسودة على هذا الجهاز والمتصفح فقط. **Save project** هو النسخة التي يمكنك نقلها أو الاحتفاظ بها. **Open project** يقبل `.flow.json` فقط؛ Lottie JSON نتيجة تصدير وليست ملف التحرير.

حدود العمل: 100 عنصر، 200 خط، 80 نقطة يدوية لكل خط، ومساحة حتى 4096 × 4096. ملفات المشاريع حتى 25 MB، وصور الاستيراد حتى 15 MB. يعمل المحرر باللمس؛ استخدم التكبير والتحريك على المساحة الفارغة لترتيب العناصر الدقيقة.
