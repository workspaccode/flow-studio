01

ابدأ هنا

  1. افتح المحرر. اختر مخطط Hybrid أو Generator backup أو Solar pump، أو ابدأ من Blank canvas.
  2. رتّب واربط. اسحب العناصر. اضغط Connect ثم المصدر والهدف. اختر الخط لتعديل المسار والزوايا والسرعة.
  3. أدخل بيانات العرض. اختر العنصر لتعديل الاسم والقيمة والوحدة والتيار والكفاءة ونص الحالة.
  4. احفظ وصدّر. Save project يحفظ ملف .flow.json قابلًا لإعادة الفتح. Export ينتج ملفات العرض.

02

على الويب، أو داخل Next.js وVue

صدّر المخطط من Export → HTML. ضع الملف مثلًا في public/flows/hybrid.html في Next.js أو Vue مع Vite، ثم اعرضه في iframe. في موقع HTML عادي، استخدم رابط الملف الذي رفعته.

HTML · embed your exported flow
<iframe
  id="energy-flow"
  src="/flows/hybrid.html"
  title="Energy flow"
  style="width:100%;aspect-ratio:1000/650;border:0"
></iframe>

بعد تحميل الملف، استدعِ واجهة التحكم من الصفحة الأم. يجب أن تكون الصفحة وملف الفلو من نفس origin للوصول إلى contentWindow بهذه الطريقة.

JavaScript · live data update
const frame = document.getElementById('energy-flow');

frame.addEventListener('load', () => {
  const flow = frame.contentWindow.energyFlow;

  flow.setNodeData('inverter', {
    name: 'الإنفرتر الرئيسي',
    value: 5.2,
    unit: 'kW',
    current: 23.6,
    currentUnit: 'A',
    efficiency: 96.8,
    status: 'يعمل',
    showDetails: true
  });

  flow.setNodeState('inverter', 'active');
  flow.setFlowState('solar', 'active');
});

كرّر التحديث عند وصول بيانات جديدة من API أو WebSocket. في Next.js، نفّذ الوصول إلى iframe داخل كود يعمل في المتصفح؛ وفي Vue نفّذه بعد تحميل العنصر والملف.

المراجع: Next.js public · Vite public assets

03

Flutter على Android وiOS

ضع HTML المصدَّر داخل ملفات التطبيق، واعرضه باستخدام webview_flutter. لا يحتاج الملف إلى إنترنت؛ ترسل بياناتك من Dart باستخدام runJavaScript.

Terminal
flutter pub add webview_flutter

احفظ الملف باسم assets/flows/hybrid.html وعرّفه في pubspec.yaml:

pubspec.yaml
flutter:
  uses-material-design: true
  assets:
    - assets/flows/hybrid.html

هذه شاشة كاملة كمثال. يتم تفعيل JavaScript وإرسال البيانات بعد اكتمال تحميل الصفحة:

Dart · WebView + data bridge
import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:webview_flutter/webview_flutter.dart';

class EnergyFlowScreen extends StatefulWidget {
  const EnergyFlowScreen({super.key});

  @override
  State<EnergyFlowScreen> createState() => _EnergyFlowScreenState();
}

class _EnergyFlowScreenState extends State<EnergyFlowScreen> {
  late final WebViewController controller;
  bool ready = false;

  @override
  void initState() {
    super.initState();
    controller = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..setNavigationDelegate(NavigationDelegate(
        onPageFinished: (_) async {
          ready = true;
          await updateInverter({
            'name': 'الإنفرتر الرئيسي',
            'value': 5.2,
            'unit': 'kW',
            'current': 23.6,
            'currentUnit': 'A',
            'efficiency': 96.8,
            'status': 'يعمل',
            'showDetails': true,
          });
          await controller.runJavaScript(
            "energyFlow.setNodeState('inverter', 'active');"
          );
        },
      ))
      ..loadFlutterAsset('assets/flows/hybrid.html');
  }

  Future<void> updateInverter(Map<String, dynamic> data) async {
    if (!ready) return;
    await controller.runJavaScript(
      "energyFlow.setNodeData('inverter', ${jsonEncode(data)});"
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Energy flow')),
      body: SafeArea(child: WebViewWidget(controller: controller)),
    );
  }
}
القيم تتغير أثناء التشغيل.

استدعِ updateInverter(data) من داخل الشاشة عند وصول بياناتك الجديدة. استخدم معرّف أي عنصر آخر مع setNodeData، ونفس الأسلوب لتفعيل أو تعطيل الخطوط. المثال موجّه لـ Android وiOS؛ على Flutter Web استخدم تضمين HTML داخل المتصفح.

مرجع الحزمة: webview_flutter. واجهة HTML مختبرة في المتصفح؛ مثال Flutter لم يُختبر على جهاز فعلي.

04

البيانات، الأسماء، والحالات

status هو نص الحالة المعروض مثل «يعمل» أو «عطل». أما حالة الظهور فتُرسل إلى setNodeState أو setFlowState.

الحالةالعنصرالخط
activeظاهر بالكاملالمسار ظاهر والحركة تعمل
inactiveظاهر باهتًاالمسار ظاهر بدون حركة
hiddenمخفي بالكاملمخفي بالكامل
JavaScript · controls
energyFlow.setNodeState('battery', 'inactive');
energyFlow.setFlowState('grid', 'hidden');

// 1: source → target | -1: target → source
energyFlow.setFlowDirection('battery', -1);

energyFlow.pause();
energyFlow.play();

// Read IDs, positions, values and states
const project = energyFlow.getProject();

إرسال مجموعة تحديثات

يمكنك أيضًا إرسال بيانات عدة عناصر وحالات الخطوط في حدث واحد داخل صفحة الفلو:

JavaScript · event payload
window.dispatchEvent(new CustomEvent('energy-flow-data', {
  detail: {
    nodes: {
      solar: { name: 'الألواح', value: 7.2, unit: 'kW' },
      battery: { value: 2.1, unit: 'kW', status: 'يشحن' }
    },
    flows: {
      solar: 'active',
      battery: 'active',
      grid: 'inactive'
    }
  }
}));

معرّفات مشروعك الحالي

هذه العناصر والخطوط الموجودة الآن في المحرر. اختر المعرّف المطابق لمخططك المصدَّر.

النوعالاسمالمعرّف ID
الاسم ليس هو المعرّف.

تغيير اسم العنصر لا يغيّر id. إضافة عنصر جديد أو تغيير المخطط قد ينتج معرّفات مختلفة. لا تفترض أن كل ملف يحتوي على نفس العناصر.

05

اختر صيغة التصدير المناسبة

الصيغةالاستخدامتحديث البيانات
HTMLويب أو Flutter WebView، حركة وواجهة تحكمنعم، بالقيم والأسماء والحالات
SVGمخطط قابل للتكبير مع مسارات متحركة وصور مضمّنةلا يتضمن واجهة energyFlow
PNGصورة ثابتة عند وقت محدد، بدقة 1× أو 2× أو 3×لقطة ثابتة
Lottie JSONتشغيل الحركة في مشغل Lottieالأسماء والقيم الحالية صور مضمّنة
.flow.jsonحفظ المشروع وإعادة فتحه في المحررقابل للتحرير بعد إعادة الفتح
لو تحتاج إلى بيانات حية، استخدم HTML.

ملف Lottie الحالي يحفظ تسميات القيم والأسماء كصور؛ لا يحتوي على دوال تحديثها الموجودة في HTML. لا يمكن فتح Lottie JSON كملف تحرير في Flow Studio.

قبل التصدير

  • تأكد من القيم والأسماء وحالات الظهور.
  • إذا خرج المحتوى خارج المساحة، استخدم Canvas settings → Fit canvas to content.
  • الخلفية الشفافة متاحة لـ SVG وPNG وLottie.
  • للحلقة المتصلة في Lottie، استخدم مدد حركة متوافقة؛ نفس المدة لكل الخطوط هو الخيار الأسهل.
